# Finalidade do repositório

Este repositório está reservado para o serviço `ai-billscanner` da organização Solaria. Pelo nome, o serviço deve extrair dados de faturas de energia (contas de luz) via OCR/IA — coerente com o domínio de energia solar já visto em [`api-core`](https://github.com/Solierrr/api-core) (que já modela faturas de energia) — mas isso ainda não foi confirmado em código, já que o repositório contém apenas `LICENSE` e este README. Nenhuma linha de código de aplicação foi commitada até o momento.
